# fitness-complete.com

Beginner starter kits for gym, Pilates, running, home gym and pickleball. Static Astro site deployed on Vercel.

## Setup

```sh
cp .env.example .env   # set AMAZON_ASSOCIATE_TAG
npm install
npm run dev            # http://localhost:4321
npm run check          # type check
npm run build          # static build to ./dist
```

Requires Node 24. Product data lives in `src/data/`. See `CLAUDE.md` for content rules and the monthly link check.
